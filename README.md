# Broken Stitch Detection in Garment Manufacturing

**Research repository — ICEEICT 2027 working project**

This repository tracks an auditable **PyTorch reconstruction** of the image-classification experiments described in an unpublished 2022 undergraduate thesis, together with planned source-disjoint testing and StitchingNet external evaluation.

> **Scientific status:** The original model weights, code and independent test metrics have not been recovered. The thesis's **94.91%** was a *reported validation accuracy*, not a newly verified test result. Unit tests use synthetic images and are **not** scientific benchmark results.

The dataset is not redistributable here without checking provenance and image rights. See `docs/RESEARCH_PROTOCOL.md` and `code/README.md` for the audit and evaluation gates.

- **Code:** `code/`
- **ICEEICT IEEE manuscript (working draft):** `paper/`
- **Colab dataset-audit notebook:** `notebooks/`
- **Research protocol and historical-result distinctions:** `docs/`

**Submission disclaimer:** Research evaluation on the actual 2.15 GB archive remains pending; do not treat the manuscript as accepted or submission-cleared.
